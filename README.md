# AURORA · 极光 — AI 创作与工作流平台落地页

暗色编辑风 + 玻璃拟态 + 极光渐变的中文营销展示落地页，单文件 `index.html`（内嵌 CSS/JS，无外部图片依赖，Google Fonts 在线加载并带本地回退）。

## 特性

- Hero 大字报式排版 + 极光渐变标题动画
- 玻璃拟态仪表盘（纯 CSS 数据可视化）
- 品牌走马灯、滚动显现（IntersectionObserver）
- 数字滚动统计、工作流代码窗口、客户评价
- 响应式布局，零构建依赖，可直接静态部署

## 使用

直接用浏览器打开 `index.html`，或部署到任意静态托管：

```bash
npx serve .
```

## 目录结构

```
aurora-landing/
└── index.html    # 全部页面（HTML + CSS + JS）
```
